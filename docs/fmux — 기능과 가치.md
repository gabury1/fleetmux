# fmux — 기능과 가치

> tmux 위에서 도는 **AI 에이전트 함대 관제탑**. bash 단일 파일(1453줄) + fzf + tmux.
> 명령 `fmux`(별명 `tt`), 프로젝트명 fleetmux. 2026-07-23 하루 만에 초판, 이후 이틀간 실전 담금질.

## 0. 한 줄

**여러 Claude/Codex 세션을 tmux에 띄워놓고 일할 때, "누가 일하고 누가 나를 기다리는지"를 화면을 안 봐도 알게 해주고, 재부팅으로 다 날아가도 대화까지 되살려준다.**

## 1. 왜 만들었나 — 해결한 진짜 문제

파이 한 대에 Claude 세션 5~6개를 띄워 함대로 굴리는 운용에서, 매일 겪던 마찰 네 가지:

| 마찰 | 그전엔 | fmux |
|------|--------|------|
| 어느 세션이 일하는 중인지 모름 | 하나씩 들어가서 눈으로 확인 | 목록에 ✻ 실시간 |
| **승인 기다리며 멈춘 세션을 몇 시간 뒤 발견** | 우연히 들어가야 앎 | ⏸ + 상태바 집계 |
| 부재중 끝난 작업을 놓침 | 기억에 의존 | ✓ 안읽음 뱃지, 목록 최상단 |
| **폰 원격제어(rc)가 조용히 풀림** | 밖에서야 발견 | 1분마다 자동 복구 |
| 재부팅 = 함대 전멸 | 손으로 10세션 재건 | `--restore` 한 방 |

## 2. 핵심 설계 — 화면을 긁지 않는다

초판은 화면(스피너 문구·화면 해시)을 긁어 상태를 판정했고 **세 번 실패**했다.

1. 작업중 문구가 변형 다수 — `(26s · ↓ 763 tokens)` / `· Channeling… (11s · thinking with xhigh effort)`
2. idle 세션도 하단 상태줄(리밋 %)이 째깍여 "활동"으로 오인
3. 접속만 해도 창 크기 재조정으로 줄바꿈이 바뀌어 또 오인

**결론: 화면은 내용이 아니라 렌더링이다.** 그래서 **Claude Code 훅**으로 전환 — 에이전트가 자기 상태를 직접 신고한다.

```
[claude/codex]  ──훅 이벤트──▶  fmux --hook <상태>  ──▶  ~/.cache/tt/hook-<세션id>
   UserPromptSubmit → working                              │
   Stop             → idle                                 ▼
   Notification     → waiting(⏸)                    fzf 목록 · 상태바 · 알림
   SessionStart     → boot
```

훅은 에이전트 프로세스의 자식으로 돌기 때문에 `$TMUX_PANE`을 상속한다 → **"이 이벤트가 어느 tmux 세션 것인지"가 공짜로 풀린다**(로그 파일로는 못 푸는 매핑 문제).

## 3. 주입 방식 — 전역 설정 무침습

훅을 남의 `~/.claude/settings.json`에 심는 건 침습적이다. 대신 **PATH shim**:

```bash
~/.local/libexec/tt/claude   # PATH 선두에 놓인 wrapper
  → tmux 안이면:  exec 진짜claude --settings "$(fmux --hooks-json)" "$@"
  → tmux 밖이면:  exec 진짜claude "$@"          (투명 통과)
```

- 전역 설정 **한 글자도 안 건드림**. wrapper 파일 하나 지우면 개입이 완전히 사라진다
- alias(`cc='claude'`) 경유 호출도 잡힌다 — alias는 글자 치환, PATH 검색은 그 다음 단계라서
- Codex도 동형(`-c hooks.Stop=...` 주입 + `--dangerously-bypass-hook-trust`)

원조는 cmux(macOS 네이티브 터미널)의 수법. 우리는 그걸 tmux/SSH 세계로 옮겼다.

## 4. 기능 목록

### 관제 (fzf 팝업, `Option+←`로 어디서든 소환)
- `→`/Enter 진입 · `←`/Esc 닫기 · `^D` tmux 탈출
- `^N` 새 세션(이름+시작명령 질문) · `^E` 개명(Claude `/rename` 자동 동기화) · `^X` 삭제 · `^R` 갱신
- 미리보기: 그 세션 화면 실시간(하단 고정 — 입력창·승인 프롬프트가 보이는 자리)
- 정렬: **안읽음 > 최근 대화 > 이름**, 도구 세션(yazi·lazydocker 등)은 청록으로 맨 아래 사전순

### 상태 표시
| 표시 | 뜻 |
|------|-----|
| **굵은 이름** | 6시간 내 대화 |
| 흐린 이름 | 조용한 세션 |
| ● | 접속 중 |
| ✻ | 작업 중 |
| ⏸ | **승인/입력 대기 — 나를 기다리는 중** |
| ✓ | 부재중 완료, 아직 안 봄 |
| ⊘ | rc 끊김(자동 복구 중) / 빨강이면 3회 실패 후 포기 |

상태바에 함대 집계 `⏸2 ✻3` + 완료 뱃지 `✓세션명`(방문하거나 10분 뒤 소멸).

### 브로드캐스트
Tab으로 세션 여럿 찍고 Enter → 프롬프트 일괄 주입. **도구 세션은 자동 제외**(셸에 문장을 치면 명령으로 실행되는 사고 방지).

### 함대 생존 (`--snapshot` / `--restore`)
매니페스트에 세션별로 `이름 · cwd · 종류 · 시작명령 · 대화id · 대화 홈cwd` 6필드를 기록.
- 1분 cron + 팝업 열 때 자동 스냅샷 → **굳히기 행위 자체가 없다**
- `--restore`: 살아있는 세션은 건너뛰고, 도구는 명령 재실행, 에이전트는 `claude --resume <id>`
- 안전장치: `--continue` 금지(폴더 최신 대화를 물어 도플갱어 발생), 살아있는 대화 선점 검사, transcript 실존 확인, 백업 3세대, 쓰기 전 무결성 검사(필드 수·uuid 형식)

### rc(원격제어) 자동 복구
`~/.claude/sessions/<pid>.json`의 `bridgeSessionId`가 비면 끊김 → `/remote-control` 재주입 → Esc로 모달 닫고 → 8초 뒤 검증.
- 작업중(busy)이면 유예(입력 오염 방지), 정상 세션엔 무개입
- **재발 브레이크**: 복구 성공 후 5분 내 또 끊기면 주입 중단(3회면 포기) — 못 고치는 브리지 버그에 매분 키를 치지 않게
- 배경: Claude Code의 rc 브리지가 25분 타임아웃·컴팩션·유휴로 조용히 죽는 공식 미해결 버그(#34868 등), 공식 해법이 "수동 재실행"뿐이라 그걸 자동화한 것

### 프로그램용 인터페이스
`--list` `--status` `--rc` `--hook` `--hooks-json` `--codex-hooks` `--cron` `--snapshot` `--restore` `--forget` `--preview` — 사람은 팝업으로, 스크립트·에이전트는 CLI로 같은 문을 쓴다.

## 5. 차별점 (경쟁 조사 후 정직하게 좁힌 것)

이 동네 도구 140개를 훑고 **아픈 정정 두 개**를 받았다:
- 훅 기반 상태추적은 차별점이 아니라 **입장권**(여럿이 이미 함)
- PATH shim도 superset이 씀 → 주장은 "**전역 설정 무침습**"으로 좁혀야 정확

살아남은 진짜 차별점 셋:

1. **rc 링크 헬스 자동복구** — 확인된 범위에서 이걸 하는 도구는 없다
2. **스크립트로 읽히는 ⏸ 승인대기** — 상태가 파일·CLI로 나와서 다른 자동화에 물릴 수 있다
3. **worktree 비강제 + bash 단일 파일** — 남의 워크플로우를 강요하지 않고, 런타임 설치 0

## 7. 요구사항 · 이식성

- **필수**: tmux ≥3.2(팝업), fzf ≥0.64(footer), bash
- **리눅스** 전부 / **macOS** 호환 작업 완료(GNU 전용 옵션 제거, `readlink -f` 대체) / **Windows는 WSL2로만**(tmux가 네이티브에 없음)
- 상태는 `~/.cache/tt/`, 매니페스트도 거기. 지우면 초기화될 뿐 손실 없음

## 9. 만들어진 방식 (이 도구 자체의 이야기)

하루 만의 picker 요청 → 이틀 만에 함대 관제탑. 방향 전환은 전부 사용 중 발견된 마찰에서 나왔다:
"화면 바뀜=활동이 틀렸다" → 훅 전환, "훅으로 식별 못 하나" → SessionStart 활용,
"claude 가로챌 수 있는 거 아냐" → PATH shim, "코덱스도 되겠네" → 다중 에이전트.

그 과정에서 밟은 지뢰가 곧 이 도구의 내용물이다 — 스피너 문구 변형, 상태줄이 해시를 오염, cron 로케일,
`$PPID`가 일회용 셸, fzf 괄호 파싱, 맥이 Ctrl+←를 삼킴, tmux `-t` 접두 매칭 오타겟,
재부팅 후 session id 재발급, `--continue`가 만든 도플갱어, 매니페스트 필드 off-by-one.
