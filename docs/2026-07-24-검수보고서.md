# fleetmux 함대 검수 보고서 (2026-07-24)

> 프로젝트명 **fleetmux** · 명령 **`fmux`**(짧은 별명 `tt`). 이 문서 본문의 `tt`는 개명 전 표기이며 같은 도구를 가리킨다.
> 실체: `~/.local/bin/fmux` (개명 2026-07-24 밤), wrapper `~/.local/libexec/tt/{claude,codex}`

> ultracode 검수: 에이전트 18기 + TUI 렌즈 별동대 1기. 렌즈 6개(셸 정확성 / 상태머신·동시성 / 코드 위생 / 훅 확장 / 3-페르소나 사용성 / TUI 풀타임 유저), 버그 주장 전건 적대검증.
> 대상: `~/.local/bin/tt` + `~/.tmux.conf` 바인딩 + `~/.claude/settings.json` 훅 8개 + `~/.cache/tt` 상태 계층.

## 0. 배경 한 줄

화면 긁기(스피너 grep·해시 추적)로 3번 실패하고 Claude Code 훅 기반 상태머신으로 전환한 도구. 이 문서는 오픈소스화 전 정밀 검수 결과이자 실행 계획 정본.

## 1. 확정 버그 11건 (전건 재현/논증 검증)

### 치명

| # | 버그 | 요지 | 수정안 |
|---|------|------|--------|
| 1 | 공백 세션명 → `--status` 전역 크래시 | finished가 공백 구분이라 `my proj`가 name/ts 분리 파괴 → set -u 즉사. 상태바 뱃지 전체 소멸, poison 라인 영구 잔존 (샌드박스 재현) | ts를 마지막 필드로 파싱 + 숫자 검증 + malformed 드롭. tmux 타깃 `-t "=$name"` 정확일치 |

### 주요

| # | 버그 | 요지 | 수정안 |
|---|------|------|--------|
| 2 | 공백명 첫 단어 절단 → 오타겟 | picker {1}·`%% *` 추출이 첫 필드만 → tmux -t 접두 매칭으로 **엉뚱한 세션 kill 가능** (실기기 재현) | 이름을 탭 구분 단일 필드로 전면 플러밍(`--delimiter '\t'`) + `-t "="` |
| 3 | `/` 포함 이름이 finished sed 파손 | 이스케이프 클래스에 `/` 누락 → sed 파스 에러가 `\|\| true`로 삼켜져 중복 누적, 주입 여지 | 클래스에 `/` 추가 또는 awk 정확일치 dedup |
| 4 | finished lost-update 레이스 | `--status`(5초 폴링, 비원자 재작성) vs idle 훅(sed -i + append) 충돌 → **부재중 완료 알림 조용히 유실** (결정적 재현) | `flock`으로 finished 변이 직렬화 |
| 5 | SessionEnd 빈 sid → hook-* 누수 | pane 소멸 경합 시 display-message가 rc=0+빈 출력 → clear가 `hook-`만 지움. 재부팅 후 id 재발급 시 stale 상태 오적용 (고아 hook-21 실증) | `[ -n "$sid" ]` 가드 + boot 시 고아 sweep |

### 기각 1건

- async 훅 순서 역전(Stop 뒤 늦은 working) — 160회 적대 재현 0회, 훅 실행 72ms ≪ 이벤트 간격. 제시 증거는 정순서 오독.

**근본 진단**: 상태 파일 계열 버그(4·5·7·8)의 공통 원인 = "hook-\*는 id 키, finished만 이름 키, 락 없음"의 비일관성. 개별 패치보다 **저장 계층 일괄 정리**(전부 id 키 + flock)가 싸다.

## 2. 코드 위생 Top 5

1. **브로드캐스트가 도구 세션에도 키 주입** — 프롬프트 문장이 셸/lazydocker에서 명령으로 실행되는 안전사고 경로. Claude 필터 최우선
2. macOS 비호환 2종: GNU `sed -i`, `read -t 0.01`(bash 3.2 불가)
3. 의존성 검사·`tt doctor`·`tt install` 부재 (fzf --footer 최신 전용, 훅 8개 수동 설치)
4. Claude 판정 로직 3중 불일치 + 브로드캐스트 로직 중복 → `is_claude_session()`·`tt_broadcast()` 함수화
5. 색·임계값(6h·10min·5min 등) 이중 하드코딩 → config/환경변수 추출

## 3. 훅 확장 아이디어 Top 5

1. **`tt --json` 상태 API** — 수집 루프를 함수로 추출하는 관문 리팩터. 이후 모든 기능이 싸짐. "엔진+얇은 UI" 구조의 기반
2. 마지막 도구 한 줄 요약 (`✻ Edit tt`) — 목록만 훑어도 각 워커의 현재 행동
3. 도구 실패 연속 ⚠ 뱃지 (PostToolUseFailure) — 부재중 삽질 루프 조기 발견
4. 부재중 완료·대기 텔레그램/webhook 중계 (`TT_NOTIFY_CMD`로 일반화)
5. waiting을 PermissionRequest 이벤트로 승격 + 도구명 표시 (단 bypassPermissions 발화 검증 선행)

## 4. 사용성 Top (3-페르소나 + TUI 풀타임)

1. **waiting 감지 확대** — 플랜 승인·AskUserQuestion 대기가 ⏸로 안 뜨는 건 최대 신호 누락
2. **상태바 함대 집계 `⏸2 ✻3`** — 가장 급한 신호(⏸)가 팝업 안 열면 안 보임 (maintainer 승인)
3. `tt <이름>` 직행 점프 + 도구 프리셋 (`tt files` → yazi 재소환)
4. 프리뷰 tail(하단 고정) + 스크롤 — ⏸ 세션 "무슨 승인 기다리나" 트리아지
5. `tt rc` — 세션 rc URL 표면화 (rc 유저의 폰 이어받기)
6. `tt --restore` — 재부팅 후 함대 재소환 (매니페스트)
7. 숫자 핫점프 (1~4 즉발)

- 반영 완료: 멀티윈도우 오분류 (전 pane 스캔으로 수리, 07-24)
- 기각: Alt-Tab 최근 세션 토글 (maintainer — 안 쓸 듯)

## 5. 실행 계획

### A. 핫픽스 (반나절) — 실피해 경로 차단
공백명 --status 크래시 가드 → sed `/` 이스케이프 → 빈 sid 가드 → finished flock → 브로드캐스트 Claude 필터 → waiting grep 확대 → 프리뷰 tail → 상태바 ⏸✻ 집계

### B. 오픈소스 전 — 남의 환경에서 첫날 터질 것들
상태 저장 계층 통일(전부 id 키+flock, #4·5·7·8 일괄) → 공백명 탭 플러밍(#2) → macOS 호환 → `tt doctor`/`install`/버전검사 → 함수화·config 추출 → comm= 생존판정(#6) → hook.log 회전(#9) → 가짜 ✓ debounce(#10)

### C. 백로그 — 순서가 비용 결정
`tt --json` 먼저 → 도구 요약·실패 ⚠ → 텔레그램/webhook → `tt <이름>`·`tt rc`·`tt --restore`

추가 근거(07-24 maintainer 관찰): 현재 삭제·생성이 인터랙티브 전용이라 스크립트/Claude는 raw tmux를 두드려 **tt 상태 살림(hook-*·finished 정리)을 우회**하게 됨 — 고아 파일 버그의 공범 경로. `tt kill/new/<이름>` 비대화형 서브커맨드로 사람·프로그램이 같은 문을 쓰게 해야 함.
